# 별점 받는 구글 폼 만들기

사이트에서 누른 별점은 이 폼에 응답으로 들어가고, 응답이 시트의 "평가" 탭에 쌓입니다.
Apps Script를 쓰지 않으니 권한 승인이 필요 없습니다.
사람들은 이 폼을 직접 열지 않습니다. 사이트가 대신 제출합니다.

## 1. 폼 만들기
새 구글 폼을 하나 만들고, 아래 17개 질문을 **이 순서와 이 이름 그대로** 추가합니다.

- 질문 유형은 전부 **단답형**으로 둡니다. 객관식으로 만들면 보기에 없는 값이 들어올 때 제출이 거부됩니다.
- **필수는 모두 끕니다.**
- 설명이나 응답 확인 규칙은 넣지 않습니다.

| # | 질문 이름 |
|---|---|
| 1 | 카카오ID |
| 2 | 매장명 |
| 3 | 업종 |
| 4 | 카카오분류 |
| 5 | 주소 |
| 6 | 위도 |

| 17 | 요청ID |

## 2. 폼 설정
- **설정 → 응답 → "로그인 필요"** 항목을 모두 끕니다. "조직 내 사용자로 제한"과 "응답 1회로 제한"도 꺼야 합니다. 이게 켜져 있으면 사이트에서 보낸 응답이 조용히 버려집니다.
- **응답 탭 → 스프레드시트에 연결 → 기존 스프레드시트 선택**에서 지금 회식각 시트를 고릅니다.
- 시트 아래에 "설문지 응답 시트2" 같은 새 탭이 생깁니다. 이 탭 이름을 **평가**로 바꿉니다. 이름을 바꿔도 폼과의 연결은 끊기지 않습니다.
- "평가" 탭의 맨 오른쪽 빈 열 두 칸에 머리글 **검증**과 **영업상태**를 직접 적습니다. 운영자가 손으로 채우는 칸입니다.
  - 검증: `완료`라고 적으면 쩝쩝박사 인증 배지가 붙습니다.
  - 영업상태: `폐업`이라고 적으면 그 가게가 사이트에서 사라집니다.

## 3. 사이트에 연결
1. 폼 편집 화면 오른쪽 위 **⋮ → 미리 채워진 링크 가져오기**를 누릅니다.
2. 각 칸에 **질문 이름을 그대로** 적습니다. 카카오ID 칸에는 `카카오ID`, 매장명 칸에는 `매장명`을 적는 식으로 17칸 모두 채웁니다.
3. **링크 가져오기 → 링크 복사**를 누릅니다.
4. 복사한 링크를 `index.html`의 `CONFIG.RATE_FORM`에 따옴표 안에 붙여넣습니다.

사이트는 이 링크를 보고 어느 칸이 어느 질문인지 스스로 짝을 맞춥니다.
나중에 질문을 바꾸면 2~4단계를 다시 하면 됩니다.

## 4. 기존 데이터 옮기기 (선택, 한 번만)
```bash
KAKAO_REST_KEY=키 node tools/migrate-legacy.mjs
pbcopy < tools/out/rating-migrate.tsv
```
"평가" 탭의 머리글 바로 아래 첫 빈 행 A열을 누르고 붙여넣습니다.
붙여넣은 다음부터 사이트는 옛 폼 응답 시트를 더 읽지 않습니다.

## 확인
- 사이트에서 별점을 하나 남깁니다. 1분쯤 뒤 "평가" 탭에 한 줄이 생기면 성공입니다.
- 남긴 사람 화면에는 시트 반영을 기다리지 않고 바로 보입니다.
- 줄이 안 생기면 2단계의 로그인 설정부터 확인합니다.
